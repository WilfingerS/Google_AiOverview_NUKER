# Google_AiOverview_NUKER

No more Google AI Overviews.

This browser extension automatically hides Google's AI Overview when loading search results.

## Install

### Local
Clone or download this repository:

```bash
git clone <https://github.com/WilfingerS/Google_AiOverview_NUKER>
```

### Browser

1. Open your browser's extension/add-on page.
2. Enable **Developer Mode**.
3. Select **Load Temporary Add-on** / **Load Unpacked**.
4. Select the extension's `manifest.json`.

That's it. Google AI Overviews will be hidden automatically.
